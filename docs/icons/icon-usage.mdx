## Clarity and contextual relevance

- Icons should be easily recognizable and understandable.
- Use icons that are contextually appropriate and convey the intended message.
- Avoid using icons that could be misinterpreted or confusing.

## Status icons

- We provide a set of standard icons to convey status.
- These icons follow a criticality hierarchy and should be used with the corresponding colors.
- For stronger emphasis or greater visual weight, use the `-filled` variant.
- To ensure consistency across different applications, do not use these icons outside of their intended use cases.
- For advanced status indication scenarios, including attaching status icons to components, see the [Badge](../components/badge/guide.md) component.

## Standard and filled icon variants

- Many icons are also available as a filled variant, indicated by the `-filled` suffix.
- Filled variants can be used when stronger visual distinction or greater visual weight is needed.

## Icons within components

- Most of our components come with built-in icons or offer an optional icon slot.
- Within the same context, use components consistently, either with or icons or without them.

![Icons within components](https://www.figma.com/design/wEptRgAezDU1z80Cn3eZ0o/iX-Documentation-illustrations?node-id=5259-16957&t=ulQZQESQGAMR3uyt-4)

## Standalone icons

- Pair standalone icons that do not have visible text with a tooltip that explains their meaning, and ensure that the description is available to screen readers.
