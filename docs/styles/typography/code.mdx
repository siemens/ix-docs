# Typography - Code

## Typography component

The `ix-typography` component provides consistent text formatting without relying on utility classes. Theme changes apply to its text automatically.

<Api />

## Utility classes

The default stylesheet includes `.typography-*` classes for native HTML elements. If you load the foundation and a theme separately instead, import the utility stylesheet before using the classes:

```css
@import '@siemens/ix/css/utilities.css';
```

```html
<span class="typography-h3">Heading text</span>
```

The Sass entry point generates the same utilities:

```scss
@use '@siemens/ix/scss/utilities';
```

Use a supported font mixin when you need a custom class without generating all utilities:

```scss
@use '@siemens/ix/scss/mixins/fonts';

.my-class-name {
  @include fonts.typography-h3;
}
```

See [Global styles](../global-styles.md) for the side effects of the complete utility layer.
