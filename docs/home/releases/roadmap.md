# Roadmap

![Roadmap](https://www.figma.com/design/wEptRgAezDU1z80Cn3eZ0o/iX-Documentation-illustrations?node-id=6992-210&t=hNTaZnRWqmj2iF50-4)

### ✅ Completed

**🔹 Release 6.0**

- **Shared design foundation**: We adopted Siemens Design Language system tokens for colors, typography, sizing and effects, and renamed the Classic theme to Community.
- **Consistent status and visuals**: We aligned status variants, colors and icons, introduced status stripes and updated affected components to 20px icons.
- **New components**: We added [List](../../components/list) with keyboard navigation, selection and optional reordering, and [Info page](../../components/info-page) for informational page states.
- **Flexible interactions**: We added responsive content-header actions, context-menu dropdown positioning and configurable dropdown keyboard navigation.
- **Date, time and forms**: We improved display formats, locale support, confirmation flows, input clearing and validation.
- **Accessibility and reliability**: We improved skip links, screen-reader labels, keyboard and focus handling, date/time input performance and framework integrations.
- **Figma slots and layouts**: We extended native slots to more components and introduced new layout templates.

See the [V6 migration guide](../migration/6_0_0/index.md) for breaking changes and the [GitHub releases page](https://github.com/siemens/ix/releases) for all changes.

### 🚧 Work in progress

- **Inline notification**: A compact alternative to message bars for feedback within a specific section or component of a page.
- **Settings and about as modal**: Templates for settings and about information in fixed-width or full-screen modals, with access moving from the bottom-left navigation menu to the application header.

### 🗓️ Scheduled

- **Patterns**: We curate patterns as copy-paste code examples that show how multiple components work together in real UI scenarios. Patterns give users practical, ready-to-use starting points beyond components.
- **Vertical navigation menu rework**: Our vertical navigation will change in alignment with other design systems at Siemens.
- **Density options**: [Sizing tokens](../../styles/sizing.md) allow sizes and spacing to adapt to different densities without creating component variants. Compact density is experimental; further work will expand density support.
- **Indeterminate progress indicator**: An indeterminate state for scenarios where the progress duration or completion time is unknown.

### ⏳ Planned

- **Box-styled tabs**: A boxed tab style containing the content below, allowing two visually distinct levels of tab navigation.
- **Resizable panes**: Adjustable pane widths and heights so users can adapt their workspace layout.
- **Icon alignment**: Semantically aligned icons representing the same actions, states or concepts across Siemens design systems.
