## What are iX patterns?

Unlike components, iX patterns are not versioned and are not automatically updated in your application. They are concrete implementations that you can copy, adapt, or install in your project using the iX CLI.

Every pattern is:

- composed of multiple iX components
- reviewed and approved by iX designers and developers
- aligned with best practices for layout, interaction, accessibility, and behavior
- copy-ready, so you can quickly adapt it for your use case
- evolving and updated over time

## How does that relate to UX design patterns?

- **UX design patterns** define a conceptual, reusable solution to a user problem, independent of any design system.
- **UI components** are the technical building blocks used to construct interfaces.
- **iX patterns** are concrete, ready-made compositions of multiple iX components that demonstrate an implementation.

UX design patterns guide the intent. iX patterns show how to implement it. Components are the raw materials.

## What is Siemens ix-cli?

The Siemens ix-cli is a command-line interface tool that allows you to easily add iX patterns to your project. With a simple command, you can integrate copyable, installable patterns into your application. It is not necessary to install the `@siemens/ix-cli` locally.
