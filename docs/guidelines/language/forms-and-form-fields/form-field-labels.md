#

Use sentence casing for all labels without periods (full stops).

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>Asset name</li>
      <li>Serial number</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>Asset name.</li>
      <li>Serial number.</li>
    </ul>
  </div>
</div>

![Serial number](https://www.figma.com/design/wEptRgAezDU1z80Cn3eZ0o/iX-Documentation-illustrations?node-id=8392-5420&t=jphHAjo9aSup2ZcT-4)

Use short labels, ideally 1-3 words.

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>Name</li>
      <li>Asset ID</li>
      <li>Email address</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>Please enter the name of the asset here</li>
      <li>Enter the asset ID of the asset</li>
      <li>Enter your email address into the field below so we can contact you</li>
    </ul>
  </div>
</div>

Don't use additional punctuation for labels unless it helps to visually distinguish labels from user input.

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>IP address</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>IP address:</li>
    </ul>
  </div>
</div>

Use nouns, not verbs, for labels whenever possible.

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>Email address</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>Add your email address</li>
    </ul>
  </div>
</div>

Don't use "please" in labels. See [Voice and tone](../basics/voice-and-tone.md#use-polite-language).

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>Installation location</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>Please enter installation location</li>
    </ul>
  </div>
</div>

## Dos and Don'ts

<div class="dos-and-donts">
  <div class="dos">
    <ul aria-label="Recommended practices">
      <li>Do ensure labels are as short and concise as possible</li>
      <li>Do make all labels grammatically the same, i.e. all nouns</li>
    </ul>
  </div>
  <div class="donts">
    <ul aria-label="Practices to avoid">
      <li>Don't add unnecessary punctuation to labels</li>
    </ul>
  </div>
</div>
