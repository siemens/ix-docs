## Divider

<SinceTag message="6.0.0" />

Key values show a divider below themselves for both label positions. Set `divider="false"` to hide it. Hidden dividers keep their space, so the layout doesn't shift when you toggle them.

```html
<ix-key-value
  label="Label"
  label-position="left"
  value="Value"
  divider="false"
></ix-key-value>
```

Inside [key value lists](../key-value-list), key values follow the `divider` setting of their list unless they set their own.

:::info
Before version 6.0.0, only key values with the label on top showed a divider. To keep standalone key values with the label on the left side without a divider, set `divider="false"`.
:::
