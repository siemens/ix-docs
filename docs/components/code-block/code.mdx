# Code block - Code

## Basic

Set `code`, and optionally `language` and `filename`. Labels of the copy button can be localized with `i18nCopy` and `i18nCopied`.

## Syntax highlighting

`ix-code-block` doesn't ship a highlighter. Set the `highlight` property to a function that receives the code and language and returns a DOM node, which replaces the plain code body. HTML strings are not supported, so create the node with DOM APIs or a highlighter that returns DOM nodes.

```ts
const codeBlock = document.querySelector('ix-code-block');
codeBlock.highlight = (code, language) => {
  const element = document.createElement('code');
  element.append(...myHighlighter(code, language));
  return element;
};
```

The same function can be used for fenced code in a [Markdown view](../markdown/code) through its `highlight` option.
