## Without divider

<SinceTag message="6.0.0" />

By default, all key values in key value lists show a divider below themselves, including the last one. Set `divider="false"` on key value lists to hide all their dividers. Key values that set their own `divider` keep their setting. Dividers and `striped` are independent, so you can combine them as needed.
