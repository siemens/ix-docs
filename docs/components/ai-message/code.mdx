## Activity trace

Place an `ix-chat-activity-trace` in the `trace` slot to show how the AI produced the response. Add one `ix-chat-trace-item` per step and structure its detail with one `ix-chat-trace-item-section` per unit of data, e.g. each input, the output or key findings. Show entities such as assets or files with [chips](../chip) or [pills](../pill).

<ChatActivityTracePlayground height="28rem" />

The components are controlled. Your application sets `summary`, `state` and `expanded` and handles `expandedChange`; the events do not bubble.

- **Waiting:** While the AI works and nothing specific is running, show a single Trace item with `state="running"` and a generic label such as "Thinking…". If only a trace is slotted, the AI message shows the trace alone.
- **Running:** Without `summary` the Trace items are shown flat. A running item shows a spinner and sets `aria-busy`.
- **Completion:** Set `summary` (and optional metadata in the `summary-meta` slot, e.g. duration or step count) and `expanded="false"` to collapse the trace. To keep the items visible, set `expanded` together with `summary`. Items keep their DOM identity and focus when the summary appears; if they are collapsed while one has focus, focus moves to the summary toggle.
- **States:** Use `completed`, `warning` or `failed` when a step ends. Show interrupted steps as `warning` with an explanatory label, e.g. "Stopped". The state is part of the accessible name, e.g. "Read page.tsx, failed"; localize it with the `i18nState*` properties.
- **Detail:** A Trace item without detail content is shown as static text. With detail content it becomes a toggle. Set `collapsible` on a section to let users collapse long content such as the output.

Recommended `icon` per step type: reasoning `bulb`, retrieval `search`, computation `calculator`, generation `ai`, system action `cogwheel`, workflow `chain-step`, read `document`, summary `list-text`, generic `circle-dot` (default).

If you migrate from Element chat messages: `activity-trace` maps to `ix-chat-activity-trace` in the `trace` slot, `activity` to `ix-chat-trace-item`, each `input` entry and the `output` to one `ix-chat-trace-item-section` each, and `loading` to `state="running"`.
