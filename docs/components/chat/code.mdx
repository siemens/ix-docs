## Welcome screen

Place an `ix-chat-welcome` in the `welcome` slot of the chat. The chat shows it only while the default slot has no messages and hides it as soon as the first message element is added, so you don't toggle its visibility yourself.

Set a greeting with `heading`, describe what the assistant can do in the default slot and add `ix-chat-prompt-suggestion` elements to the `suggestions` slot. Each Prompt suggestion is a button with its text as accessible name. Handle `suggestionSelect` to fill the chat input or submit the prompt directly; the event detail is the suggestion text and the event bubbles, so you can listen on the chat.

## Message actions and Follow-up prompts

Add message actions to the `actions` slot of [AI messages](../ai-message) and [user messages](../user-message): tertiary [icon buttons](../icon-button) with an `aria-label` for copy, regenerate and feedback (thumb up and down), and an icon button that opens a [dropdown](../dropdown) for further actions.

Use `ix-chat-prompt-suggestion` as Follow-up prompts in the `follow-up` slot of the [chat input](../chat-input) so they look like the Prompt suggestions of the Welcome screen. Plain [buttons](../button) keep working in this slot.
