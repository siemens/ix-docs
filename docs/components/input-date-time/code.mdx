## Require confirmation

By default, every pick is applied immediately and **Done** closes the picker. Set `requireConfirmation` to only apply the value when users click **Confirm**. **Cancel**, <kbd>Escape</kbd> or clicking outside discards the pending selection. `valueChange` is only emitted for applied values.
